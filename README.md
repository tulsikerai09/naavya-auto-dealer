# Naavya AI – Auto Dealer Demo (React + Vite)

## Run
    npm install
    npm run dev

## Build
    npm run build && npm run preview

## Customise
- `src/App.jsx`: set SALES_WHATSAPP_LINK, MEETING_LINK, CLIENTS; wire your backend in `submit()`
- `public/`: replace mascot.png and jms-tech-logo.png with your real images
  (then update MASCOT_SRC / JMS_LOGO_SRC in App.jsx)
